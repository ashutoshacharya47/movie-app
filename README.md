# movie-app
A simple movie search web application where users can search for movies and view details like posters, ratings, release dates, and descriptions.

## 🚀 Features

- 🔍 Search movies by name
- 🎞 View movie posters
- ⭐ Movie ratings
- 📅 Release dates
- 📖 Short movie descriptions
- 📱 Responsive design

---

## 🛠 Tech Used

- HTML
- CSS
- JavaScript
- Movie API (TMDb)
